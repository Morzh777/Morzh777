## 🚀 О себе

Разрабатываю backend, веб-интерфейсы и AI/ML системы. Пишу на TypeScript и Python, проектирую микросервисную архитектуру, работаю с базами данных, API и большими языковыми моделями.

## 🛠️ Использую технологии

**Backend:** Node.js, NestJS, Python, gRPC, REST API  
**Frontend:** Next.js, React, 
**Базы данных:** PostgreSQL, SQLite, Redis,  
**DevOps:** Docker, Nginx, Git  
**AI/ML:** Ollama, Telegram Bot API, AI/ML
